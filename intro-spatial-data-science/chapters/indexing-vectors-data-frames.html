4  Indexing Vectors and Data Frames

NoteLearning objectives

By the end of this chapter you should be able to:

  1. Index a vector by position, by a logical condition, and by name.
  2. Write comparisons and combine them with the logical operators &, |, and !.
  3. Create a data frame and pull out its rows, columns, and values.
  4. Read a table of data from a CSV file into R.

So far you have created values and stored them in variables. Most of the work of data analysis, though, is not creating data but picking out the part of it you need: the counties with incomes above the state median, the flights that left LaGuardia in June, the census tracts inside one city. Selecting part of a vector or table is called indexing, and it is the subject of this chapter.

We start with vectors, which you met in the last chapter, and three ways to index them: by position, by a logical condition, and by name. Then we stack vectors side by side into a data frame, R’s table, and finish by reading a table from a file.

4.3 Logical operations

4.3.1 Comparisons return TRUE or FALSE

TRUE and FALSE are special values in R, called logical or Boolean values (after the mathematician George Boole). Every comparison operator returns one of them (Table 4.3).

Notice that “equal to” is written with two equals signs, ==. A single = does something different: it sets an argument inside a function call, as in round(x, digits = 1). Mixing them up is one of the most common errors in R, and you will see it again when you start filtering data.

Now put that logical vector inside the brackets. R keeps the elements in the TRUE positions and drops the rest:

The result is 25, 50, 100, 200, 500, and 1000: every value greater than 10. Read vect[vect > 10] out loud as “the elements of vect where vect is greater than 10.” This is the single most useful idea in the chapter. 4.3.4 Logical vectors are recycled

What if the logical vector is shorter than the vector you are indexing? R recycles it, repeating it until it is long enough. Here c(TRUE, FALSE) becomes TRUE, FALSE, TRUE, FALSE, ..., ten values in all:

The result is every other value, starting with the first: 1, 5, 25, 100, and 500. Recycling is handy now and then, but it can also hide mistakes, so make sure a logical index is the same length as the vector unless you mean it to be shorter.

4.3.5 Combining conditions: AND, OR, and NOT

Often you need two conditions at once: values greater than 10 and less than 500, say. R has three logical operators for combining TRUE and FALSE values.

AND (&) is TRUE only when both sides are TRUE. Is the statement “the sun rises in the west AND humans breathe oxygen” true? No: the first part is false, so the whole statement is false.

OR (|) is TRUE when either side is TRUE (or both). “The sun rises in the west OR humans breathe oxygen” is true, because the second part is. On most keyboards the vertical bar | is on the backslash key, above Enter.

With AND, only TRUE & TRUE gives TRUE. With OR, only FALSE | FALSE gives FALSE.

4.4.1 Naming the elements

The third way to index uses labels. The function names() attaches a name to each element of a vector. The vector of names must be the same length as the vector of data:

The values haven’t changed; each one now just has a label printed above it (Table 4.6).

4.4.2 Selecting by name

Put a name, in quotation marks, inside the brackets:

vect["Fozzie"] returns 10, because Fozzie is the fourth name and position 4 holds 10. vect[c("Kermit", "Scooter")] returns 1 and 100, each with its name attached. Use straight quotation marks ("), not the curly ones a word processor inserts, or R won’t recognize them.

Names make code easier to read, and they keep working if the order of the elements changes. vect["Fozzie"] still finds Fozzie’s value even if someone sorts the vector; vect[4] would quietly return whatever has moved into position 4. This is the same reason you will refer to the columns of a data frame by name.

4.5 Data frames

4.5.1 From one dimension to two

A vector is one-dimensional: a single row of values. Stand several vectors of the same length side by side, and you get a two-dimensional table. In R, that table is a data frame, and it is how R stores almost every data set you will work with, including, later in the course, spatial data.

A data frame is organized into rows and columns (Table 4.7):

  • Each column is a variable: something measured or recorded, such as a name or an exam score.
  • Each row is an observation: one thing that was measured, such as a student, a county, or a flight.
  • All the values in a column must have the same data type. Each column is a vector, and, as you saw in the last chapter, a vector holds just one type. Different columns can have different types.

Here name and exam1 are character columns, exam2 is numeric, and bonus is logical. Suppose a number, such as 75.4, crept into the exam1 column of letter grades. R would not keep a number in a character column: it would coerce the 75.4 into the text "75.4". The same thing happens in reverse, and causes more trouble: a single letter or symbol in a column of numbers, such as "N/A" in exam2, turns the whole column into text, and then you can no longer average it.

4.5.4 Indexing a data frame

The same bracket indexing works on data frames, with one change: a data frame has two dimensions, so the brackets take two indexes, separated by a comma. The row comes first, then the column: grades[row, column].

Leaving a position blank means “all of them,” so grades[2, ] is the whole second row and grades[, "exam2"] is the whole exam2 column. Don’t forget the comma: without it, R treats the number as a column index, not a row.

Because pulling out one column is so common, R has a shortcut, the dollar sign. grades$exam2 returns the exam2 column as a vector, which you can then use like any other vector:

4.6 Reading tabular data

You will rarely type a data set in by hand. Usually it arrives as a file, and the most common format is a CSV file (comma-separated values): plain text in which each line is a row and commas separate the values. The first line usually holds the column names, called the header. Here is the grades table as a CSV file:

name,exam1,exam2,bonus
Eliza,A,98.1,TRUE
Shonda,A-,85.4,TRUE
Me'shelle,A,74.3,FALSE
Jack,A-,92.2,TRUE

Base R has two functions for reading text files like this into a data frame.

read.table() is the general-purpose workhorse. It reads any table of text in which the values are separated by some character, called the delimiter, and it has many options, including:

  • header: is the first row the column names (TRUE or FALSE)?
  • sep: the delimiter, such as "," for commas or "\t" for tabs.
  • row.names and col.names: labels for the rows and columns.
scores <- read.table("scores.txt", header = TRUE, sep = "\t")

read.csv() is read.table() with its defaults set for CSV files, sep = "," and header = TRUE, so usually all it needs is the file name:

scores <- read.csv("scores.csv")

Its sibling read.csv2() reads the kind of CSV file common in much of Europe, which uses a comma as the decimal mark (3,14) and a semicolon to separate values.

Remember from Section 3.4 that R looks for the file relative to the folder your .Rmd file is saved in. If the CSV file is in the same folder, the file name alone is enough; if it is in a data subfolder, write read.csv("data/scores.csv"). Most “cannot open file” errors are file path errors.

4.8 Summary

  • Indexing selects part of a vector or table, with square brackets. R counts positions from 1.
  • By position: vect[3] is the value at position 3; vect[-3] drops it; vect[c(1, 3)] and vect[6:8] return several values. The colon operator : makes a sequence.
  • Comparison operators (>, <, >=, <=, ==, !=) return TRUE or FALSE for every element. Equality is ==; a single = sets an argument.
  • By condition: vect[vect > 10] keeps the elements where the condition is TRUE. Combine conditions with & (AND: both must be true), | (OR: either can be true), and ! (NOT). Short logical vectors are recycled.
  • By name: names() labels the elements, and vect["Fozzie"] selects by label. length() counts elements, and vect[length(vect)] is the last one.
  • A data frame is a table of equal-length vectors: columns are variables, rows are observations, and each column holds one data type. Make one with data.frame(), and index it with df[row, column] or df$column.
  • Read CSV files with read.csv() (or read.table() for other delimiters), and check the column types after you read.
