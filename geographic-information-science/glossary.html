Glossary

Key terms used in this book. In the chapters, a term with a dotted underline shows its definition when you hover over it, tap it, or reach it with the Tab key.

A missing value: nothing was recorded. NULL fails every comparison, so test for it with IS NULL.
.csvt file
A one-line file next to a CSV that sets the data type of each column for QGIS and GDAL, such as “String”,“Integer”.
3D Elevation Program (3DEP)
The USGS program that collects lidar and publishes free elevation data and DEMs for the whole United States.
absolute location
A location given in a coordinate system that means the same thing to everyone, such as 38° 53′ 52″ N, 77° 02′ 11″ W.
accessibility
How easily people can reach a place or service, often measured as distance or travel time.
ACS 1-year estimates
ACS estimates from 12 months of data, published only for areas with 65,000 or more people.
ACS 5-year estimates
ACS estimates from 60 months of data, published for every area down to block groups.
active sensor
A sensor that sends out its own signal and measures what comes back, as radar and lidar do.
adaptive sampling
Sampling in passes: a sparse first pass, then more samples where values change quickly.
address matching
Geocoding an address by comparing it with a reference file whose features already carry address information.
address point
A point for one address, often placed on the rooftop or the building entrance.
address range
The lowest and highest house numbers on one side of a street segment.
affine transformation
A six-coefficient transformation that corrects translation, scale, skew, and rotation. Needs at least 3 GCPs.
aggregation
Rescaling a raster to coarser cells by combining blocks of cells into one, using a statistic such as the mean, sum, or majority.
Albers Equal-Area Conic
An equal-area conic projection, the standard for measuring areas across the contiguous United States (EPSG:5070).
altitude
For a hillshade, the sun’s angle above the horizon; the default is 45°.
American Community Survey (ACS)
The Census Bureau’s yearly sample survey of about 3.5 million addresses, the main source of social, economic, and housing data.
Analytic Hierarchy Process (AHP)
A method, developed by Thomas Saaty, that derives weights by comparing criteria two at a time on a scale of 1 to 9.
anisotropy
Spatial dependence that changes with direction. Its opposite is isotropy, the same dependence in every direction.
annotation
Text placed on a map, such as place names, street names, and labels.
apportionment
Dividing the 435 seats in the U.S. House of Representatives among the states, by population.
arc
A line stored as an ordered list of coordinates. Polygons can be built from arcs that share their end points.
arc-second
1/3,600 of a degree. As a DEM cell size, 1 arc-second is about 30 m on the ground.
ARC/INFO
Esri’s command-line GIS, first released in 1982.
Arcade
Esri’s expression language, used for calculating fields, labels, and pop-ups in ArcGIS Pro and ArcGIS Online.
ArcGIS Online
Esri’s system for making and sharing maps and layers on the web.
ArcGIS Pro
Esri’s commercial desktop GIS, for Windows.
ArcMap
Esri’s main desktop GIS application from 1999 until ArcGIS Pro replaced it. Esri ended support for it on March 1, 2026.
ArcPy
Esri’s Python library for running ArcGIS tools and automating work in ArcGIS Pro.
arithmetic progression
A classification method in which each class is wider than the one before by a constant amount.
aspect
The compass direction a slope faces, in degrees clockwise from north (0° north, 90° east, 180° south, 270° west).
asserted data
Data contributed by the public, such as OpenStreetMap. Their accuracy is undocumented and uneven.
attribute
A non-spatial fact about a feature, such as a building’s name or the year it was built. Attributes are stored in a table with one row per feature.
attribute accuracy
How correct the non-spatial values in a dataset are, such as a feature’s type or name.
authoritative data
Data from official agencies, collected under documented standards and published with metadata.
average neighbor
An interpolation method that estimates each location as the mean of the observations within a search radius.
azimuth
A compass direction, in degrees clockwise from north. For a hillshade, the direction the sunlight comes from; the default is 315°.
azimuthal
A projection onto a plane that keeps true directions from its center point.
bag
A collection that can contain duplicates. A table is a bag unless a primary key forbids repeated rows.
bandwidth
The radius of a kernel. Small bandwidths show local hot spots; large ones show regional patterns.
basemap
A background map, such as streets, topography, or aerial imagery, that gives context to the layers drawn on top of it.
batch geocoding
Geocoding a whole table of addresses in one run.
Big Data
Datasets too large, too fast, or too varied for traditional tools, often described by three Vs: volume, velocity, and variety.
bilinear interpolation
Resampling that averages the four nearest input cells, weighted by distance.
binary
Base-2 numbers, written with only 0 and 1, in which each column is worth twice the one to its right. Computers store all data in binary.
bit
A binary digit, 0 or 1. With n bits you can write 2ⁿ different values.
block group
A cluster of census blocks within a tract, usually with 600 to 3,000 people. The smallest area with ACS estimates.
breakline
A line along a ridge, stream, or road edge where the slope changes sharply, used to keep those features crisp in a terrain model.
Browser panel
The QGIS panel that shows folders, databases, and web services, from which data can be dragged onto the map.
buffer
The region within a specified distance of a point, line, or polygon.
bull’s-eye
A ring of values around a single observation that differs from its neighbors; a sign of IDW interpolation.
CAD
Computer-aided design: software for drawing buildings, parts, and other objects. It is spatial but not geographic, because its drawings aren’t tied to places on Earth.
Canada Geographic Information System (CGIS)
The first large GIS, built in the 1960s under Roger Tomlinson to inventory land across Canada.
cardinality
How many records in one table match each record in another: one-to-one, many-to-one, one-to-many, or many-to-many.
cartographic boundary files
Simplified census boundaries clipped to the shoreline, for small-scale maps.
cartographic modeling
Planning and running a chain of spatial operations to solve a problem, where each operation’s output becomes the next one’s input. The term is Dana Tomlin’s.
cartography
The art and science of making maps.
Catalog pane
The ArcGIS Pro pane that shows a project’s maps, layouts, toolboxes, databases, and folder connections.
cell
One square in a raster grid. Each cell holds one value. In an image, a cell is called a pixel (picture element).
cell size
The real-world length of one side of a raster cell, such as 30 meters. Smaller cells give finer resolution and larger files.
census block
The smallest census area, bounded by streets, streams, and other visible features. Decennial counts only.
census geography
The hierarchy of areas for which census data are published, from the nation down to the block.
census tract
A relatively permanent subdivision of a county with 1,200 to 8,000 people, about 4,000 on average.
census-designated place
An unincorporated community that the Census Bureau defines so that it can publish statistics for it.
central meridian
The meridian at the center of a projection or zone, such as the line along which a Transverse Mercator cylinder touches the Earth.
centroid
The center point of a polygon.
change detection
Comparing images or maps of the same place from different dates to find what changed.
changeset
A group of edits to OpenStreetMap saved together, with the editor’s username and a comment.
check point
A point with known coordinates that is not used to fit a transformation, kept back to test its accuracy.
choropleth map
A map that shades each area, such as a county, by its value, usually in a few classes from light to dark.
class break
A value that divides one class from the next on a classed map.
classed map
A choropleth map in which values are grouped into a few classes, each shown with one shade.
client/server
A design in which client programs send requests to a server, which does the work and sends back the answer.
clip
An overlay that keeps only the parts of a data layer inside a bounding layer, keeping only the data layer’s attributes.
closed way
In OpenStreetMap, a way (an ordered list of nodes) whose first and last nodes are the same, forming an area such as a building.
cluster
A group of events or features that are closer together than you would expect by chance, such as cases of a disease around one place.
cluster tolerance
A distance within which vertices are treated as the same point during overlay, to prevent slivers.
coefficient of variation (CV)
The standard error as a percentage of the estimate. Over about 40 percent, an ACS estimate is usually treated as unreliable.
cokriging
Kriging that also uses one or more correlated secondary variables, such as elevation when predicting temperature.
ColorBrewer
A free online tool with tested color schemes for maps, for 3 to 9 classes.
complement
Every record outside a set. NOT selects the complement.
completeness
An element of data quality: what is missing from a dataset, and what is there that shouldn’t be.
composite vulnerability index
One index that combines several vulnerability indices; in the Dhaka study, physical plus social vulnerability minus coping capacity.
compromise projection
A projection that preserves no property exactly but keeps every distortion moderate, such as Robinson or Winkel Tripel.
concurrency
Many users reading and editing a database at the same time, without overwriting each other’s changes.
conditional function
The raster version of if-then-else (CON in ArcGIS Pro): where a condition is true, take one value or raster; where false, another.
confidence level
How often a range built the same way would contain the true value, if the survey were repeated many times.
conformal
A projection that keeps local angles true, so small shapes look right. Mercator and Lambert Conformal Conic are conformal.
confusion matrix
A table that cross-tabulates mapped classes against true classes at test sites; the diagonal holds the correctly classed sites.
consistency ratio (CR)
An AHP measure of how far pairwise judgments are from perfectly consistent. Below 0.10 is usually acceptable.
Contents pane
The ArcGIS Pro pane that lists the layers in the active map or the elements of the active layout.
contextual tab
A ribbon tab in ArcGIS Pro that appears only when a certain kind of item, such as a feature layer, is selected.
contiguity
Touching. Contiguous polygons share a border (rook’s case) or a border or corner (queen’s case).
continuous data
A quantity that has a value at every location and changes gradually from place to place, such as elevation, temperature, or rainfall.
continuous ranking
A ranking in which values are scaled smoothly from worst to best, so a near miss scores higher than a poor value.
Continuously Operating Reference Stations (CORS)
A network of permanent GPS receivers, run by the National Geodetic Survey and its partners, that keeps NAD83 up to date.
contour interval
The difference in elevation between neighboring contour lines on a map, such as 20 feet.
contour line
A line on a map joining points of equal elevation. Lines close together mean a steep slope.
control point
A point on the ground, often marked with a bronze disk, whose coordinates have been measured precisely. Control points tie a datum to the Earth.
coordinate reference system (CRS)
The full description of how coordinates relate to the Earth: a datum, plus a projection with its parameters, plus units.
coordinate system
A system of numbers, such as latitude and longitude, that gives every location a unique position so layers line up with each other.
Copernicus GLO-30
A free global elevation model with 30 m cells, made from the TanDEM-X radar mission. It is a surface model, including trees and buildings.
coping capacity
The ability of people and organizations to manage a hazard event using the skills and resources they already have (UNDRR).
copyright trap
A deliberate error, such as a made-up town or street, put on a map to reveal copying.
cost distance
Distance measured as an accumulated cost, such as travel time or effort, across a cost raster, rather than in meters.
credits
The currency an ArcGIS organization uses to pay for some services, such as batch geocoding and storing data in ArcGIS Online.
crisis mapping
Mapping by volunteers to support the response to a disaster or other crisis.
crispness
A visual variable for uncertainty: sharp edges for known boundaries and blurred edges for uncertain ones.
criterion
A condition a site must meet in a suitability model, first written in plain language and then as a measurable threshold, such as slope < 30°.
critical GIS
The study of the social effects of GIS and mapping, including who benefits, who is represented, and how to use GIS more fairly.
cross validation
Testing an interpolation by removing each observation in turn, estimating it from the rest, and recording the error.
CSV
A plain-text table in which values are separated by commas, one record per line.
cubic convolution
Resampling that uses the 16 nearest input cells.
CyberGIS
GIS built on high-performance and cloud computing, so large analyses can be split across many processors.
dasymetric map
A map that redistributes values within each area onto the land where they occur, such as placing people only where there are homes.
data abstraction
The chain of steps that turns the real world into something a computer can store: real world, data model, data structure, and machine code.
data lifecycle
The stages a dataset passes through: collection, processing, storage, display, and use. Uncertainty can enter at each one.
data model
The way a GIS represents the real world as data, for example as points, lines, and polygons (vector) or as a grid of cells (raster).
Data Source Manager
The QGIS dialog for adding layers of every kind: files, delimited text, databases, and web services.
data structure
How a data model is laid out in a computer’s memory or files, for example as lists of coordinate pairs linked by pointers.
data type
How a field is stored, such as text, integer, double, or date. It limits what the field can hold.
database
An organized collection of tables, usually stored and managed by a database management system.
database management system (DBMS)
Software that stores data once and lets many programs and people query and edit it, while it controls who may change what.
datum shift
The difference in where the same latitude and longitude land on the ground in two different datums. Between NAD27 and NAD83 it can exceed 100 m.
datum transformation
Equations or a grid of measured shifts that convert coordinates from one datum to another.
De Morgan’s law
NOT (A AND B) equals (NOT A) OR (NOT B), and NOT (A OR B) equals (NOT A) AND (NOT B).
decennial census
The full count of every U.S. resident, taken every ten years as the Constitution requires.
decimal degrees (DD)
Latitude or longitude written as one signed number, such as −79.0558. Negative numbers are south latitudes and west longitudes.
definition query
In ArcGIS Pro, a WHERE clause that hides the features that fail it, until you remove it. QGIS calls this a filter.
degrees, minutes, and seconds (DMS)
Latitude or longitude written in degrees, minutes (1/60 of a degree), and seconds (1/3,600 of a degree), with a hemisphere letter, such as 79° 03′ 21″ W.
demographic data
Data on who lives in a place: counts of people and households, and their age, sex, race and ethnicity, and household type.
density
A count divided by an area, such as people or crimes per square mile.
deprivation index
A single score that combines several socioeconomic variables to measure how disadvantaged an area is.
destination table
In a join, the table that receives the new fields. All of its records are kept.
deterministic interpolation
Interpolation in which the surface is fully determined by a formula and the chosen parameters, with no statistical model of error.
developable surface
A shape that can be unrolled flat without stretching: a plane, a cylinder, or a cone.
differential privacy
A method that adds calibrated statistical noise to published tables, so that individuals cannot be identified.
digital elevation model
A raster whose cell values are elevations of the ground surface.
digital surface model
An elevation model of the first surface a sensor hits, including tree canopies, roofs, and power lines.
digital terrain model
A bare-earth elevation model with breaklines added along ridges, streams, and other features.
digital twin
A detailed, regularly updated digital model of a real city, building, or system, often 3D and linked to live sensor data.
digitize
To create vector features by drawing them, clicking each point or vertex on a map or image.
discrete object
Something with clear boundaries that is either present or absent at a location, such as a road, a house, or a state.
discrete ranking
A ranking in which each value either passes (1) or fails (0) a criterion.
dissolve
An operation that merges features sharing a value in a field, removing the boundaries between them.
distance join
A spatial join that matches each feature to the closest feature, or to every feature within a set distance, and can record the distance.
diverging color scheme
Two hues that meet at a light neutral color, for data with a meaningful midpoint such as a mean or zero.
Double
A 64-bit data type for decimal numbers, with about 15 significant digits. Float is the 32-bit version, with about 7.
easting
A distance east from a starting line: the x coordinate in a projected coordinate system.
ecological fallacy
Assuming that every person or place in an area shares the area’s average value.
Economic Census
The Census Bureau’s survey of businesses, taken every five years in years ending in 2 and 7.
edge effect
Locations near the boundary of a study area find fewer neighbors than they should, because their neighbors outside it were not observed.
elevation angle
The angle up (positive) or down (negative) from an observer to a point, arctan of the change in elevation over the horizontal distance.
ellipsoid
A smooth mathematical model of the Earth’s shape: an ellipse rotated about its polar axis, wider at the equator than from pole to pole. Examples are Clarke 1866, GRS 80, and WGS 84.
ellipsoid height
Height above the ellipsoid, written h. This is the height a GPS receiver measures.
entity
A real-world object we want to store as data, such as a tree, a building, or a lake. On a map, an entity is shown as a feature.
enumeration unit
An area for which data are collected and reported, such as a county, census tract, or state.
epidemiology
The study of how diseases are distributed and spread in populations. John Snow’s 1854 cholera map is a founding example.
EPSG code
A number that identifies a coordinate reference system in the EPSG registry, such as 4326 for WGS84 or 32119 for North Carolina State Plane.
equal interval
A classification method that divides the range of the data into classes of equal width.
equal-area
A projection that keeps relative area true. Use one to measure or compare areas, or to map density.
equator
The parallel halfway between the poles, at 0° latitude. It is the only parallel that is a great circle.
equidistant
A projection that keeps true distance from one or two points, or along certain lines.
error
The difference between a recorded value and the true value, which we usually can’t know exactly.
Esri
The company that makes ArcGIS, founded in 1969 by Jack and Laura Dangermond in Redlands, California.
Euclidean distance
Straight-line distance. As a raster function, each cell’s distance to the nearest source cell.
exact interpolator
An interpolation method whose surface passes through every observed value.
exposure
The people, property, systems, or functions that could be lost because of a hazard; who and what is in harm’s way.
expression
A formula of fields, values, operators, and functions that computes a value for each feature, used to calculate fields, select features, and control labels and symbology.
extent
How far something reaches: its size, boundary, and dimensions. A layer’s extent is the rectangle that just encloses all its features.
extrapolation
Estimating values beyond the observations: outside the area they cover, or above or below the observed range.
extrinsic quality assessment
Measuring the quality of a dataset by comparing it with an authoritative reference dataset.
FAIR principles
Guidelines saying that good data should be Findable, Accessible, Interoperable, and Reusable (Wilkinson et al. 2016).
false easting
A value added to every x coordinate so that none are negative, such as 500,000 m in UTM.
feature
How a map or a GIS represents an entity, usually as a point, a line, or a polygon, with attributes that describe it.
feature class
Esri’s term for a vector layer stored in a geodatabase: a set of features with the same geometry type and fields.
field
A column in an attribute table: one attribute, measured the same way for every feature. Also called an attribute or item.
field calculator
A tool that computes values and writes them into a field, for every record or for the selected records only.
file coordinates
Positions in a raster given as pixel columns and rows.
FIPS code
A numeric code the U.S. government assigns to each state, county, and other area, such as 37 for North Carolina and 37135 for Orange County.
first return
The first echo of a lidar pulse, from the first thing it hits, such as a treetop or a roof. First returns build a DSM.
first-order neighbor
A polygon that touches the polygon in question directly. Its own neighbors are second-order neighbors.
fitness for use
Whether a dataset or map is good enough for a particular purpose, which depends on the use as much as on the data.
flattening
How squashed an ellipsoid is: f = (a − b) / a. For the Earth, about 1/298.
Fleming and Hoffer’s method
A way of estimating slope from only the four direct neighbors of a cell.
flowchart
A diagram of a model’s input data (rectangles), operations (ovals), and their order (arrows), used to plan and document the model.
focal function
A map algebra function that computes each cell’s output from a moving window of nearby cells, such as a 3×3 mean.
foreign key
A field that holds values of another table’s primary key. Its values can repeat.
foundation model
A large AI model pretrained on a huge dataset, such as an archive of satellite images, that can be adapted to many tasks with little new labeled data.
full outer join
A join that keeps every record of both tables.
GDAL
The Geospatial Data Abstraction Library, open-source software that reads and writes hundreds of raster and vector formats. QGIS, ArcGIS Pro, and many other programs use it.
GeoAI
Artificial intelligence applied to geographic data, for example to find buildings or roads in satellite images automatically.
geocoding
Turning an address or place name into coordinates, so it can be put on a map.
geodatabase
Esri’s format for storing feature classes, tables, and rasters together. A file geodatabase is a folder ending in .gdb.
geodesic distance
Distance measured along the curved surface of the ellipsoid, rather than on a flat projected map.
geodesy
The science of measuring the Earth’s size, shape, orientation in space, and gravity field.
geodetic datum
A model that fixes an ellipsoid’s size, shape, and position relative to the Earth, realized by a network of control points, so latitude and longitude point to real places. Examples are NAD27, NAD83, and WGS84.
geographic coordinate system (GCS)
A coordinate system that gives positions as latitude and longitude, in degrees, on a datum. EPSG:4326 (WGS84) and 4269 (NAD83) are examples.
geographic information science (GIScience)
The theory and methods behind GIS: research on analysis, data representation, visualization, and GIS and society. Michael Goodchild named the field in 1992.
geographic information system (GIS)
“A computer-based system to aid in the collection, maintenance, storage, analysis, output, and distribution of spatial data and information” (Bolstad). Its five components are data, hardware, software, people, and procedures.
geographic problem
A problem that happens in specific places at specific times. It can be described by its scale, time, space, and purpose.
geographically weighted regression (GWR)
A regression that is fit separately at each location, weighting nearby observations more, so that relationships between variables can change across space.
GEOID
The Census Bureau’s identifier for a geographic area, made by stringing FIPS codes together. A tract GEOID has 11 characters.
geoid
The surface of equal gravity that best matches global mean sea level. It is lumpy, up to about 100 m above or below the ellipsoid, and elevations are measured from it.
geoid height
The distance from the ellipsoid to the geoid at a place, written N. In the lower 48 United States it is negative, about −30 m.
geomasking
Moving geocoded points by a small random amount to protect the privacy of the people they represent.
geometric progression
A classification method in which each class is wider than the one before by a constant ratio, suited to strongly skewed data.
geometry
The shape of a feature: a point, a line, or a polygon, stored as coordinates.
GeoPackage
An open file format (.gpkg) from the Open Geospatial Consortium that stores many vector and raster layers in a single file. It is QGIS’s default format.
geoprocessing
Running a GIS tool on spatial data to make new data, such as buffering, clipping, or overlaying layers.
Geoprocessing pane
The ArcGIS Pro pane for finding, filling in, and running geoprocessing tools.
georeferencing
Transforming a raster, such as a scanned map or image, from file coordinates to map coordinates.
geospatial
A common synonym for geographic, used especially in industry, the military, and government.
geostatistics
Statistics for spatially continuous data, which model spatial autocorrelation to predict values and their uncertainty. Kriging is its best-known method.
GIS question
A question whose answer depends on location, such as where something clusters, how places differ, what factors explain a pattern, how a place has changed, or how accessible a service is.
GIS&T Body of Knowledge
A free collection of short, peer-reviewed articles on geographic information science and technology topics, from the University Consortium for Geographic Information Science (UCGIS).
GISP
Geographic Information Systems Professional: a certification from the GIS Certification Institute for experienced GIS practitioners.
gnomonic projection
An azimuthal projection on which every great circle is a straight line.
goodness of variance fit
A measure from 0 to 1 of how well classes fit the data: 1 minus the squared deviations from the class means divided by those from the overall mean.
GPS
The Global Positioning System: U.S. satellites that let a receiver, such as your phone, work out its location. GNSS is the general name for GPS and similar systems from other countries.
graticule
The network of parallels and meridians drawn on a map.
great circle
A circle on a sphere whose plane passes through the center. The shortest route between two points follows a great circle.
ground control point (GCP)
A feature that can be found on both an image and a reference layer, used to work out the transformation between them.
hazard
An act or phenomenon that has the potential to produce harm, such as a flood, wildfire, hurricane, or earthquake.
hazard footprint
The area a hazard can reach, such as a floodplain or wildfire perimeter, often mapped with its likelihood and severity.
heat map
A map of a density surface, usually from kernel density estimation.
hillshade
A raster that shows terrain as if lit by the sun from a chosen azimuth and altitude, from 0 (shadow) to 255 (full sun).
histogram
A bar chart of how many values fall in each range, used to see the shape of a distribution.
Horn’s method
A way of estimating slope and aspect from all eight neighbors of a cell, counting the direct neighbors twice. ArcGIS Pro and QGIS use it.
Humanitarian OpenStreetMap Team
An organization that coordinates volunteer OpenStreetMap mapping for disaster response and development.
iD
OpenStreetMap’s web-based editor, which runs in a browser with no installation.
image rectification
Correcting an image’s geometry so that it fits a map coordinate system.
index contour
Every fourth or fifth contour line, drawn thicker and labeled with its elevation.
inexact interpolator
An interpolation method that smooths the data, so its surface may not pass through the observed values.
inner join
A join that keeps only the records that match in both tables.
inside join
A spatial join that matches features that contain, lie within, or intersect each other, such as points inside polygons.
integer
A data type for whole numbers. Its range depends on its bits: up to 32,767 for 16 bits, about 2.1 billion for 32 bits.
intersect
An overlay that keeps only the areas covered by both input layers, with attributes from both. The overlay version of AND.
intersection
The records in both of two sets. AND selects the intersection.
interval
Values with equal steps but an arbitrary zero, such as temperature in °C or a calendar year. Differences make sense; ratios don’t.
intrinsic quality assessment
Measuring the quality of OpenStreetMap from its own editing history, such as the number of editors and versions in an area.
inverse distance weighted
An interpolation method that estimates each location as a weighted average of nearby observations, with weights of 1 / distance raised to a power.
ISNULL
A raster function that outputs 1 where a cell is NoData and 0 elsewhere. It never outputs NoData itself.
ISO 19157
The international standard for describing and measuring the quality of geographic data.
Join_Count
The field ArcGIS Pro’s Spatial Join adds to hold the number of join features that matched each target feature.
JOSM
The Java OpenStreetMap editor, a desktop editor for advanced work.
k nearest neighbors
A neighborhood made of the k closest locations, whatever their distance.
katcha house
In Bangladesh, a makeshift dwelling of mud, bamboo, or recycled and found materials, the type most likely to be destroyed by floods.
kernel
In density estimation, a moving window that weights nearby points by their distance from the cell at its center.
kernel density estimation
A method that turns points into a continuous density surface by sliding a weighted window (a kernel) across a grid.
key
A field whose values link the records of one table to the records of another.
kriging
A geostatistical interpolation method that weights observations using a model of spatial autocorrelation (the semivariogram), and estimates the uncertainty of each prediction.
Lambert Conformal Conic
A conformal conic projection with two standard parallels. It suits mid-latitude regions that run east to west, and is used for North Carolina State Plane.
Landsat
A series of U.S. Earth-observing satellites, run by NASA and the USGS, that have imaged the whole planet since 1972, mostly with 30-meter cells.
last return
The last echo of a lidar pulse, which often comes from the ground under trees. Ground returns build a bare-earth DEM.
latitude
The angle north or south of the equator, from 0° at the equator to 90° at the poles.
layer
A set of spatial data about one theme, such as roads, soils, or elevation. Layers for the same area stack on top of each other to make a map.
Layers panel
The QGIS panel that lists the project’s layers in drawing order.
least squares
Fitting a model by choosing the coefficients that make the sum of the squared errors as small as possible.
left join
A join that keeps every record of the left (destination) table, with NULL where nothing matched. The default in QGIS and ArcGIS Pro.
legend
The part of a map that explains its symbols.
level of measurement
What kind of values an attribute holds, which decides what questions make sense: nominal, ordinal, interval, or ratio.
license level
One of the three tiers of an ArcGIS Pro license, Basic, Standard, and Advanced, each adding tools to the one below.
lidar
A remote sensing method that times laser pulses to measure distance, used to map elevation, buildings, and tree height in fine detail.
line
A vector feature with length but no area, stored as an ordered list of coordinates, such as a road or a stream.
line of sight
A test of whether a target is visible from an observer, by comparing elevation angles along the line between them.
line segment
The straight piece of a line between two vertices or nodes.
lineage
The history of a dataset: where the data came from, and how they have been collected, processed, and edited since.
linear combination
Adding suitability layers with equal weights; with 0/1 layers, the result counts how many criteria each cell meets.
linear interpolation
Estimating a position between two known points in proportion to a value between their values, such as a house number within a range.
linking table
A table with one row for each pair of related records, used to handle a many-to-many relationship.
Linus’s Law
“Given enough eyeballs, all bugs are shallow.” Applied to maps, areas edited by more contributors tend to be more accurate.
logical consistency
Whether data agree with their own rules, for example polygons that close and roads that meet at intersections.
long-term release
A QGIS version, released once a year, that gets bug fixes but no new features for about a year. It is the most stable choice.
longitude
The angle east or west of the prime meridian, from 0° at Greenwich to 180° east or west.
majority filter
A neighborhood function that gives each cell the value shared by most of its neighbors, used to clean up classified images.
manual intervals
Class breaks set by the analyst at meaningful values, such as a poverty line, or the same breaks for a series of maps.
many-to-many
Records on each side match many records on the other. Needs a linking table.
many-to-one
Many destination records match the same source record, but each matches only one. A simple join works.
map algebra
Math on rasters, cell by cell, such as adding two grids or finding every cell where slope is under 10 percent.
map generalization
Deciding what detail to keep on a map, by simplifying, classifying, and enhancing.
map projection
A mathematical method for flattening the round Earth onto a flat map. Every projection distorts area, shape, distance, or direction in some way.
mapathon
An event where volunteers map together for a few hours, often for a humanitarian project.
MapRoulette
A tool that turns detected OpenStreetMap errors into small tasks that volunteers can fix.
margin of error (MOE)
The likely range of sampling error around an estimate. Census Bureau margins of error use a 90 percent confidence level.
match rate
The share of addresses in a table that were successfully geocoded.
match score
How closely an address agrees with a candidate in the reference file, often on a scale from 0 to 100.
mean error
The average of the cross-validation errors. Near 0 means the surface is unbiased.
mean sea level
The average height of the sea surface over many years, which the geoid approximates.
Mercator
A conformal cylindrical projection from 1569, made for navigation: lines of constant compass bearing are straight. It greatly enlarges areas toward the poles.
merge rule
In ArcGIS Pro, how the values of several matching features are combined into one, such as first, sum, or mean.
meridian
A line of equal longitude. Meridians run from pole to pole and meet at the poles.
metadata
Data about data: who made a dataset, when, how, in what coordinate system, and how accurate it is.
Missing Maps
A project founded in 2014 that maps vulnerable places before disasters happen.
ModelBuilder
ArcGIS Pro’s visual tool for drawing and running a cartographic model as a flowchart. QGIS’s equivalent is the Model Designer.
moving window
A window of cells, usually 3 × 3, that slides across a raster one cell at a time while a neighborhood function runs.
multi-criteria decision analysis (MCDA)
Methods that weigh many criteria to support a decision, including GIS suitability modeling.
multiband
A raster with several values per cell, one per band, such as the red, green, blue, and near-infrared bands of a satellite image.
NAD27
The North American Datum of 1927. It used the Clarke 1866 ellipsoid and an origin at Meades Ranch, Kansas.
NAD83
The North American Datum of 1983, an earth-centered datum on the GRS 80 ellipsoid, fixed to the North American plate. The datum of most U.S. government GIS data.
named user license
An ArcGIS Pro license assigned to a person’s ArcGIS account, and checked when they sign in.
National Map Accuracy Standards (NMAS)
The 1947 U.S. standard: at scales of 1:20,000 or smaller, 90% of tested points must be within 1/50 inch on the map (40 feet at 1:24,000).
National Risk Index
FEMA’s map of risk for every U.S. county and census tract, combining expected annual losses from 18 natural hazards with social vulnerability and community resilience.
National Standard for Spatial Data Accuracy (NSSDA)
The 1998 U.S. standard that reports positional accuracy in ground units at 95% confidence, whatever the map scale.
NATRF2022
The North American Terrestrial Reference Frame of 2022, the new datum that will replace NAD83 in the United States.
natural breaks
A classification method (Jenks) that groups similar values by minimizing the variance within classes. The default in ArcGIS Pro.
nearest neighbor
The feature closest to a given feature.
neighborhood
In spatial analysis, a zone drawn around a location, defined by distance, by contiguity, or by a number of nearest neighbors.
neighborhood effect
The tendency of a place’s value to depend on the values around it.
neighborhood function
A raster function that computes a statistic from a window of cells around each cell and writes it to the center cell.
network
Connected lines and intersections, such as roads, rails, rivers, or pipes, with a cost such as length or travel time on each segment.
network analysis
Analysis of movement along a network, such as roads, to find routes and measure travel distance or time.
Next Generation 911
The digital, GIS-based 911 system that uses address points, street centerlines, and boundaries to route emergency calls and locate callers.
NoData
A code meaning a raster cell has no value. Any map algebra operation that touches NoData outputs NoData, and statistics skip it.
node
The start or end point of a line. In a network, lines meet at nodes. In OpenStreetMap, a node is any single point with a latitude and longitude, standing alone or as a vertex of a way.
nominal
Categories with no order, such as land use or a name. You can test equality and count, but not average.
non-spatial data
Data with no location of their own, such as a list of grades. When non-spatial data describe a spatial feature, they are its attributes.
normalize
To divide a count by an area, a population, or another total, so that areas of different sizes can be compared fairly.
normalized difference vegetation index (NDVI)
A measure of green vegetation from remote sensing, computed as (NIR − Red) / (NIR + Red). It ranges from −1 to 1, and dense healthy vegetation is high.
north arrow
A symbol showing the direction of north on a map.
northing
A distance north from a starting line: the y coordinate in a projected coordinate system.
nugget
The semivariance at (nearly) zero distance, from measurement error or variation smaller than the sample spacing.
on-the-fly reprojection
Reprojecting layers as they are drawn, so layers in different CRSs line up on the map without changing their stored coordinates.
one-to-many
One destination record matches many source records. Summarize the source first, or use a relate.
one-to-one
Each destination record matches exactly one source record, and the other way around.
Open Database License
The license for OpenStreetMap data. Anyone may use and share the data if they credit OpenStreetMap contributors and share derived databases under the same license.
open source
Software whose source code anyone may read, change, and share, often free of charge. QGIS and GRASS GIS are open source.
OpenStreetMap
A free, editable map of the world built by volunteers, founded in 2004.
ordinal
Ranked categories whose steps are of unknown size, such as A, B, C, D or a hurricane’s category.
ordinary kriging
Kriging that assumes an unknown but constant mean. The most common type.
orthometric height
Height above the geoid, written H: the elevation, or “height above sea level,” printed on maps. h = H + N.
OSGeo
The Open Source Geospatial Foundation, a nonprofit that supports open-source geospatial software such as QGIS, GDAL, PROJ, and PostGIS.
OSMCha
OSM Changeset Analyzer, a tool for reviewing recent OpenStreetMap edits to catch mistakes and vandalism.
Osmose
A tool that runs automated quality checks on OpenStreetMap data.
overlay analysis
Stacking layers of data for the same area to find places that meet several conditions at once, such as flat land near a road and outside a floodplain.
overshoot
A line that runs past the line it should meet: a topology error.
Overture Maps Foundation
A group founded in 2022 by Amazon, Meta, Microsoft, and TomTom to build open map data, partly from OpenStreetMap.
pairwise comparison
Judging two criteria at a time: which matters more, and by how much. In AHP the answers fill a matrix whose diagonal is 1 and whose lower half holds reciprocals.
parallel
A line of equal latitude. Parallels run east and west and get shorter toward the poles.
parcel
A polygon for one piece of property, usually with its owner and address.
partial sill
The sill minus the nugget: the part of the variation that is spatially autocorrelated.
passive sensor
A sensor that records energy it does not send out itself, such as reflected sunlight or emitted heat. Most satellite cameras are passive.
photogrammetry
Measuring positions and heights from overlapping (stereo) photographs, the way two eyes judge depth.
physical vulnerability
Vulnerability that comes from the land and buildings, such as low elevation, weak construction, or closeness to a river.
pictorial relief
Showing hills and mountains on a map as small drawings, which tell where the high ground is but not how high it is.
Plate Carrée
The projection that plots longitude as x and latitude as y on an even grid. It stretches the map east to west toward the poles.
plugin
An add-on that extends QGIS with new tools, installed from inside QGIS with Plugins ▸ Manage and Install Plugins.
point
A vector feature with a location but no length or area, stored as a single x, y coordinate pair, such as a well or a school.
point cloud
The millions of x, y, z points recorded by a lidar scanner, before they are turned into a raster.
pointer
In a data structure, a stored address that tells the computer where the next piece of data, such as the next arc, is found.
polygon
A vector feature that encloses an area: a closed line whose first and last points are the same, such as a lake, a park, or a county.
polynomial transformation
A transformation that can bend an image. Second order needs at least 6 GCPs; third order needs 10.
population density
The number of people per unit of area, such as people per square mile.
positional accuracy
How close the coordinates in a dataset are to the true positions of the features.
Post-Enumeration Survey
A survey taken after the census to measure how many people it missed or counted twice.
PostGIS
A free extension that adds geometry types and spatial functions to the PostgreSQL database.
precision
For a numeric field, the total number of digits it can hold. Scale is how many of them fall after the decimal point.
prediction standard error
Kriging’s estimate of how far off each prediction might be. It is largest where observations are sparse.
primary key
A field whose values identify each row of a table uniquely. No value may repeat or be missing.
prime meridian
The meridian at 0° longitude, through Greenwich, England, chosen in 1884. Longitude is measured east and west from it.
print layout
In QGIS, a page on which a map is arranged with its title, legend, scale bar, and other elements, for printing or export. ArcGIS Pro calls it a layout.
Processing Toolbox
The QGIS panel that holds its analysis tools (algorithms), from QGIS itself, GDAL, and GRASS GIS.
projected coordinate system
A coordinate system that gives positions as x, y in meters or feet, on a map projection built on a datum, such as UTM or State Plane.
Property Identification Number (PIN)
The unique number a North Carolina county gives each parcel, linking it to its deed, survey plats, and tax record.
proportional symbol map
A map that shows counts with symbols, such as circles, sized in proportion to each value.
QGIS
A free and open-source desktop GIS that runs on Windows, Mac, and Linux.
qualitative color scheme
Distinct hues of similar lightness, for categories rather than quantities.
quantile
A classification method that puts the same number of areas in each class. Five quantile classes are quintiles.
quartic kernel
A hump-shaped kernel that weights points most at the center and falls to zero at the bandwidth. The default in ArcGIS Pro and QGIS.
queen’s case
Contiguity in which polygons are neighbors if they share an edge or a corner.
query
A written condition that the software tests against every record, selecting those that pass.
radar
A remote sensing method in which a satellite or aircraft sends out its own microwave signal and records what bounces back. It sees through clouds and smoke, and works at night.
radial basis function
An exact interpolation method that fits a smooth, minimum-curvature surface through every observation, like a flexible sheet pinned at each point.
range
In a semivariogram, the distance at which the sill is reached. Beyond it, observations are not autocorrelated.
ranking
The scores given to the values within one criterion, putting them on a common scale, usually 0 (unsuitable) to 1 (ideal).
raster
A data model that stores the world as a regular grid of equal-sized cells, each holding one value. Best for continuous data and imagery.
rasterize
To convert vector data into a raster.
ratio
Values with equal steps and a true zero, such as population or area. Every arithmetic operation makes sense.
raw count
A total that hasn’t been normalized, such as a number of people or crimes. Raw counts grow with the size of an area.
ray casting
A point-in-polygon test that counts how often a line from the point crosses the polygon’s edge. An odd count means inside.
reclassification
Grouping the values of a layer into fewer, more meaningful classes, such as elevations into low, medium, and high.
record
A row in an attribute table: everything known about one feature.
redistricting
Redrawing the boundaries of congressional and legislative districts after each census.
redlining
Grading neighborhoods as risky for lending, as the federal Home Owners’ Loan Corporation did on maps in the 1930s, which outlined many Black and immigrant neighborhoods in red and denied them credit.
reference file
In geocoding, the layer that addresses are matched against, such as parcels, street centerlines, or ZIP Code areas.
relate
A link between two tables that lets you see the matching records without copying fields into the layer. QGIS calls it a relation.
relational database
A database that stores data in tables and links them through key fields that hold the same values.
relative location
A description of where something is in relation to a landmark, such as “ten paces north of the oak.” It only works if you know the landmark.
relative radiance
How bright a cell would look in sunlight, calculated from the sun’s azimuth and altitude and the cell’s slope and aspect.
reliability diagram
A small diagram in the margin of an older topographic map showing how and when each part of the sheet was mapped.
relief inversion
An illusion in which valleys look like ridges, and ridges like valleys, usually when a hillshade is lit from the south.
remote sensing
Collecting information about Earth without touching it, from sensors on satellites, aircraft, or drones.
reproject
To convert a layer’s coordinates from one CRS to another and save the result. Defining a projection, by contrast, only labels what the coordinates already are.
resampling
Giving each cell of a transformed raster a value from the input cells: nearest neighbor, bilinear, or cubic convolution.
residual
The difference between an observed value and the value a model predicts; in georeferencing, the distance between a GCP’s true and transformed positions.
resilience
The ability of a community exposed to a hazard to resist, absorb, adapt to, and recover from it in a timely and efficient way (UNDRR).
resolution
The level of detail in data. For a raster, it is set by the cell size: the smaller the cells, the finer the resolution.
rhumb line
A line of constant compass bearing. It is straight on a Mercator map.
ribbon
The band of tabs and grouped commands across the top of the ArcGIS Pro window.
right join
A join that keeps every record of the right (source) table.
rise over run
Slope as the change in elevation (rise) divided by the horizontal distance (run).
risk
The estimated impact a hazard would have on people, services, facilities, and structures in a community: hazard × vulnerability × exposure.
risk analysis
Mapping and measuring the likely impact of hazards on people and places, so that resources go where they prevent the most harm.
rook’s case
Contiguity in which polygons are neighbors only if they share an edge.
root mean square error (RMSE)
The square root of the average squared residual: one number that sums up how well a model fits.
route optimization
Finding the best path through a network, such as the fastest or shortest route, or a delivery route that visits many stops.
sampling design
The pattern of observation locations: systematic, random, clustered, or adaptive.
saturation
The purity of a color. As a visual variable for uncertainty, rich color marks reliable values and washed-out color doubtful ones.
scale bar
A line marked with distances that shows the map’s scale graphically. It stays correct when the map is enlarged or shrunk.
scale factor
The ratio of scale at a place on a map to the map’s stated scale: exactly 1 on a standard line, below 1 where the map shrinks the Earth, above 1 where it stretches it.
search neighborhood
The area around an unknown location, set by a radius, sectors, and a shape, from which observations are taken to estimate it.
secant
A projection surface that cuts through the Earth along two lines (or a circle), spreading the error more evenly.
selection
The records, and their features, that pass a query. A selection is temporary until you export it or calculate it into a field.
semi-major axis
The equatorial radius of an ellipsoid, written a. For the Earth, about 6,378 km.
semi-minor axis
The polar radius of an ellipsoid, written b. For the Earth, about 6,357 km.
semivariance
Half the squared difference between two observed values. Averaged over pairs in a distance bin, it measures dissimilarity at that distance.
semivariogram
A plot of semivariance against the distance between pairs of observations, described by its nugget, sill, and range.
sensitivity analysis
Changing one input, such as a weight or threshold, at a time to see whether a model’s results change. If small changes move the answer, it is fragile.
sequential color scheme
Light-to-dark steps of one or a few related hues, for data that run from low to high.
shapefile
A common vector format from Esri that stores one layer in several files with the same name: .shp (geometry), .shx (index), and .dbf (attributes) are required, and .prj holds the coordinate system.
Shuttle Radar Topography Mission (SRTM)
A Space Shuttle mission in February 2000 that mapped the elevation of most of Earth’s land with radar, at 30 m and 90 m.
sill
The semivariance at which a semivariogram levels off.
simple join
A join that copies the attributes of one source feature to each destination feature. Works for one-to-one and many-to-one relationships.
simple kriging
Kriging that assumes a known, constant mean.
sink
A DEM cell lower than all its neighbors. Most are errors, and they trap water in flow models, so they are removed with the Fill tool.
site selection
Using GIS to choose the best location for something, such as a new store, clinic, or fire station.
skewed
Describes a distribution with a long tail on one side, such as many small values and a few very large ones.
sliver
A thin, tiny polygon created by overlay where two versions of the same boundary don’t match exactly.
slope
The steepness of the ground, in degrees or percent, calculated from an elevation raster.
snap raster
A raster whose grid sets where output cell edges fall, so that the outputs of raster tools line up exactly with it.
snapping
An editing setting that makes a new vertex jump to a nearby vertex or edge, so that shared boundaries line up exactly.
social vulnerability
Vulnerability that comes from people’s circumstances, such as poverty, age, disability, language, or lack of a car, that make it harder to prepare, evacuate, and recover.
Social Vulnerability Index (SVI)
An index that ranks places by social vulnerability from census variables; the CDC/ATSDR SVI ranks every U.S. census tract.
socioeconomic data
Data on economic and social conditions, such as income, education, employment, poverty, and housing costs.
source table
In a join, the table whose fields are appended to the destination.
space-time cube
A way to organize data that change over time: a map for each time step, stacked so that x, y, and time are the three axes.
spatial analysis
Methods that use the locations of things, and the relationships among them, to find patterns, explain them, or make predictions.
spatial autocorrelation
The degree to which values at nearby locations are more alike (positive) or more different (negative) than chance would predict.
spatial cross-validation
Testing a model on whole regions held out from training, rather than on random points, so that spatial autocorrelation doesn’t make the model look more accurate than it is.
spatial data
Data tied to a location on or near Earth, such as the address of a house, the outline of a county, or the elevation at a point.
spatial data quality
How well a geographic dataset fits its intended use, described by elements such as lineage, accuracy, consistency, and completeness.
spatial interpolation
Estimating the value of an attribute at unsampled locations from observations at sampled ones.
spatial join
A join that matches the features of two layers by location instead of by a shared key, then appends attributes from one to the other.
spatial operation
A GIS function that takes one or more input layers and produces an output layer, such as a buffer, dissolve, or overlay.
spatial predicate
A rule that tests a spatial relationship between two geometries, such as intersects, contains, within, or touches.
spatial scope
The input locations used to compute the value at an output location: local (the same location), neighborhood (nearby locations), or global (every location).
spatial thinking
Using ideas of space, such as location, distance, pattern, and scale, to understand and solve problems.
spatial weights matrix
A table recording which locations are neighbors of which, and how much each neighbor counts.
spectral signature
The pattern of how much light a surface reflects at each wavelength, which lets remote sensing tell surfaces such as vegetation, soil, and water apart.
spine
The main line of census geography (nation, regions, divisions, states, counties, tracts, block groups, blocks), in which each level nests in the one above.
SQL
Structured Query Language, the standard language for asking databases questions. In a GIS you usually write only its WHERE clause.
SQLite
A small database that lives in a single file. GeoPackages are SQLite databases.
stakeholder
A person or group affected by a decision, whose views may be used to set a model’s criteria and weights.
standard deviation classification
A classification method that sets class breaks at fixed numbers of standard deviations above and below the mean.
standard line
A line where the projection surface meets the Earth, so the scale is exact. Standard lines that follow latitude are standard parallels.
State Plane Coordinate System (SPCS)
A U.S. system of about 120 zones following state and county lines, built for surveyors, with error held to 1 part in 10,000. North Carolina has one zone (EPSG:32119 in meters, 2264 in feet).
street centerline
A line along the middle of a street. Centerline files used for geocoding store the address range on each side of each segment.
Sturges’ rule
A starting point for the number of classes: about 1 + 3.3 log10(n), where n is the number of values.
suitability index
A cell’s total score in a suitability model: the sum of its weighted scores on every criterion.
suitability layer
A layer that scores every cell for one criterion, from 0 (completely unsuitable) to 1 (ideal).
suitability modeling
Ranking every location in a study area by how well it meets a set of criteria, such as choosing sites for a house, a school, or a wind farm.
summarized join
A join that counts and summarizes all the source features matching each destination feature (count, sum, mean, minimum, maximum).
symbology
The rules that control how a layer is drawn: its symbols, colors, sizes, and classes.
table join
Appending the fields of a source table to a destination table by matching the values of a key field.
tabular data
Data stored in tables of rows and columns, such as the attributes of features.
tag
In OpenStreetMap, a key=value pair that describes an element, such as highway=residential.
tangent
A projection surface that touches the Earth along one line or at one point.
Tasking Manager
HOT’s tool that divides a mapping project into small squares, so that volunteers don’t overlap and each square can be validated.
temporal quality
How current a dataset is, and how accurate its dates are.
temporal stability
How long a feature stays the same, from millions of years for mountains to months for storefronts.
temporary layer
A layer kept only in memory, such as a tool output not saved to a file. It is lost when QGIS closes.
test point
A location whose true position is known from a more accurate source, used to measure a map’s positional accuracy.
Thiessen polygons
Polygons that surround each point with all the area closer to it than to any other point.
threshold
The number or rule that turns a criterion into something software can test, such as 300 m < distance to road < 2,000 m.
TIGER/Line
The Census Bureau’s boundary files for states, counties, tracts, roads, and other features.
TIN
Triangulated irregular network: a surface model that joins sampled elevation points into triangles, using more triangles where the ground is rough.
Tissot’s indicatrix
Identical small circles drawn on the globe and then projected. Their size and shape on the map show the projection’s distortion.
Tobler’s first law of geography
“Everything is related to everything else, but near things are more related than distant things” (Tobler 1970).
topographic map
A map that shows the shape of the land with contour lines, along with streams, roads, and place names, such as a USGS 1:24,000 quadrangle.
topology
The recorded connections between features, such as which polygons share an edge and which lines meet at a node. It keeps neighbors from having gaps or overlaps.
transformation
Equations that convert image coordinates into map coordinates, with coefficients solved from ground control points.
transparency
A visual variable for uncertainty: a faded, see-through symbol tells readers to trust it less.
Transverse Mercator
A Mercator projection turned on its side, so the cylinder touches the Earth along a central meridian. It suits regions that run north to south.
trend surface
A smooth polynomial surface fit to all the observations, usually by least squares. Its order sets how many bends it can have.
triangulation
An old surveying method that measures the angles of a chain of triangles between stations to work out their positions across a large area.
Type 1 error
“Seeing wrong”: concluding that a pattern exists where none exists, like a false positive in statistics.
Type 2 error
“Not seeing”: missing a pattern that does exist, like a false negative in statistics.
unary operation
A raster operation with one input raster, such as A × 2. A binary operation has two, such as A + B.
uncertain geographic context problem
The problem that the area that actually affects a person, such as where they spend their day, may not match the unit used to study them, such as their home census tract.
uncertainty
The degree to which we aren’t sure of something: the cloud of possible values around a recorded value.
unclassed map
A choropleth map in which each area gets its own shade, in proportion to its value, instead of being grouped into classes.
undershoot
A line that stops just short of the line it should meet: a topology error.
uniform kernel
A kernel that gives every point inside the bandwidth the same weight.
union
The records in either of two sets. OR selects the union.
universal kriging
Kriging that models the trend as a function of location, such as a polynomial, and krigs the residuals.
Universal Transverse Mercator (UTM)
A system of 60 zones, each 6° of longitude wide, each a secant Transverse Mercator projection in meters. North Carolina spans zones 17N and 18N.
validation
In the HOT Tasking Manager, a check of a finished square by a second, experienced mapper.
vector
A data model that stores the world as points, lines, and polygons, each defined by x, y coordinates and linked to its attributes. Best for discrete objects.
vectorize
To convert a raster into vector features.
Venn diagram
A drawing of sets as overlapping circles, useful for checking what an AND or OR query will select.
veracity
Whether data can be trusted; sometimes called the fourth V of Big Data.
vertex
An intermediate point where a line or polygon boundary changes direction.
vertical datum
The reference surface that elevations are measured from, such as the North American Vertical Datum of 1988 (NAVD 88).
viewshed
The area visible from one or more observer points, found by running a line-of-sight test to every cell of a DEM.
visual variable
A property of a map symbol that can change to show data, such as size, shape, hue, value, crispness, transparency, or saturation.
void
A hole of NoData cells in a DEM, common in radar DEMs over steep mountains and water.
volunteered geographic information
Geographic data created by individuals, most of them not trained in mapping, and shared on the internet (Goodchild 2007). OpenStreetMap is the best-known example.
vulnerability
The susceptibility to physical injury, harm, damage, or economic loss when a hazard strikes.
web GIS
GIS delivered through a web browser: interactive maps, dashboards, and analysis that run online rather than in desktop software.
Web Mercator
The Mercator variant used by nearly every web map (EPSG:3857). Good for display, never for measuring distance or area.
weighted linear combination (WLC)
Multiplying each standardized layer by its weight and adding them, cell by cell: S = Σ wᵢxᵢ. Also called the rating model.
weighted overlay
Combining raster layers on a common scale by multiplying each by its weight and adding them; also the name of an ArcGIS Pro tool.
weighting
A multiplier that sets how much a criterion counts when suitability or vulnerability layers are combined.
WGS84
The World Geodetic System of 1984, the global, earth-centered datum used by GPS. It differs from NAD83 by about 1 to 2 meters in North America.
WHERE clause
The condition part of an SQL query, such as "Area" > 20. It is the part you write in Select by Expression or Select By Attributes.
z-factor
A multiplier that converts a surface’s z units to the units of x and y, such as when elevations are in meters but coordinates are in degrees.
ZIP Code Tabulation Area (ZCTA)
An approximation of a ZIP Code’s area built from census blocks.
ZIP+4
A nine-digit ZIP Code whose last four digits identify a short segment of a mail route, such as one side of a block.
zonal function
A map algebra function that summarizes the cells within each zone, such as the mean elevation of each watershed.
zonal statistics
A statistic, such as the mean or sum, computed for all the raster cells within each zone of a zone layer.
